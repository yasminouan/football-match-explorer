# ⚽ Football Match Explorer

Application web qui permet d'explorer les statistiques d'un match de football, avec un graphique **xG (Expected Goals)** cumulé minute par minute.

🔗 **Démo en ligne :** https://yasminouan.github.io/football-match-explorer/

![Aperçu du projet]()

## Fonctionnalités
- Choix d'un match de la Coupe du monde 2022
- Graphique xG cumulé pour chaque équipe
- (À venir) Shot Map, Pass Map, Pass Network

## Technologies
- HTML, CSS, JavaScript
- Chart.js
- Données ouvertes StatsBomb

## Source des données
[StatsBomb Open Data](https://github.com/statsbomb/open-data)

## Lancer le projet en local
```bash
git clone https://github.com/yasminouan/football-match-explorer.git
cd football-match-explorer
python -m http.server 8000
```
Puis ouvrir http://localhost:8000
